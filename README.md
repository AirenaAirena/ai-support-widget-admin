# AI Support Widget — Admin Panel

This is the admin panel for my AI Support Widget project. Business owners can register, log in, and manage their support chat here.

## What it does

- Register a new business account
- Log in and see conversations from visitors
- Manage knowledge base documents (used by the bot to answer questions)
- Edit business settings (welcome message, contact info, widget color)

## Tech stack

- React
- TypeScript
- Vite
- Supabase (Auth, PostgreSQL, RLS)
